# AI 应用开发 12 周学期计划（大一版）

> 原 8 周版是"每天 2–3 小时"的强度，不适合有课业压力的大一。
> 这一版按 **每周 2 次 × 2.5 小时 = 5 小时** 设计，12 周共约 **60 小时**。
> 目标不变：**手里有 2 个能演示的项目 + 一个能投简历的 GitHub**，但范围砍掉一半。

---

## 三条铁律（比计划本身重要）

1. **GPA 优先。** 考试周、赶作业周，这一周就跳过，不补课、不内疚。
2. **固定两个时段。** 比如周三晚 + 周日下午，各 2.5 小时。**时间固定比时长重要。**
3. **做不完就顺延。** 计划是地图不是合同，落后一周不丢人，停下来才丢人。

## 每周做什么

### 第 1 周：Python 快速过
- 语法对照 C：没有 `;`、没有 `{}`、用缩进
- 列表 `[]`、字典 `{}`、`for x in ...`、函数 `def`
- 文件读写：`open()` + `with`
- **验收**：写个脚本，读一个 txt，统计每个字出现次数，打印前 5 名
- 资源：B 站「彭彭 Python」前 20 集 / 官方教程前 5 章

### 第 2 周：记账本（第一个项目）
- 功能：加一笔、删一笔、按月统计、存 JSON
- 只用 Python 标准库，不装任何包
- **验收**：关掉程序再打开，数据还在

### 第 3 周：工程化
- `python -m venv .venv` + `pip install`
- 拆成 `main.py` / `storage.py` / `report.py`
- 写 `requirements.txt` 和 README
- **验收**：换台机器照 README 能跑起来

### 第 4 周：调 LLM API
- 注册一个兼容 OpenAI 接口的服务（DeepSeek 等），拿 Key
- 学会 `messages` 结构、`system` 提示、温度参数
- **Key 放环境变量**，`.gitignore` 掉 `.env`
- **验收**：命令行输入问题，打印模型回答

### 第 5 周：多轮对话
- 维护 `messages` 列表，把历史带上
- 记录 token 用量，算一次对话多少钱
- **验收**：连续追问 5 轮不跑题

### 第 6 周：RAG 上半 —— 切分与检索
- 概念：chunk → embedding → 向量检索 → 拼进 prompt
- 用 `sentence-transformers` 或 Chroma，把一份 PDF 切块存起来
- **验收**：输入一个问题，能检索出最相关的 3 段原文

### 第 7 周：RAG 下半 —— 接入问答
- 检索结果 + 问题 → 拼 prompt → 调模型 → 输出答案和出处页码
- **验收**：问 5 个文档里的细节，至少答对 3 个

### 第 8 周：RAG 调优
- 调 chunk 大小、重叠、top-k，对比效果
- 记录"答错的问题"，分析是检索错还是模型错
- **验收**：10 个问题答对 ≥7 个

### 第 9 周：Agent 上半 —— 工具调用
- function calling 流程：模型给结构化调用 → 你执行 → 结果回灌
- 只做一个工具（读文件 / 查天气 / 算数）
- **验收**：模型能正确触发那个工具并用到结果

### 第 10 周：Agent 下半 —— 兜底与多步
- 最大步数限制、失败重试、参数校验
- **验收**：故意给错参数，Agent 能报错并自我修正一次

### 第 11 周：网页化
- Streamlit 写一个页面：上传 PDF → 提问 → 显示答案
- **验收**：同学用浏览器能打开并提问

### 第 12 周：包装
- README：一句话简介、截图、怎么跑、技术选型
- 录 90 秒 Demo：上传 → 提问 → 回答 + 出处
- 简历写一行：做了什么、用了什么、效果如何（带数字）
- **验收**：陌生人照 README 能跑通
